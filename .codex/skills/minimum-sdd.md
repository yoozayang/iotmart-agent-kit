# Minimum SDD

Before implementation or a design change:
- Read the supplied WI/spec, affected source, and routed system context.
- State: change summary, affected files/systems, expected behavior, validation, open questions/risks.
- Separate confirmed scope from unresolved decisions; do not implement unresolved choices.
- For authorized Notion persistence, use `.codex/skills/task-notion-record.md`; local planning alone does not load it.
